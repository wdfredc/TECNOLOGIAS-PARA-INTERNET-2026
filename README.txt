Projeto Web - ConectaWeb

Esse pacote foi revisado para atender à Ficha de Avaliação da disciplina Tecnologias para Internet.

O que já está implementado:
- HTML semântico com header, nav, main e footer.
- Organização em pastas: /css, /js, /imagens e /secreto.
- Layout responsivo com Flexbox/Grid e media queries.
- Variáveis CSS no :root.
- Animações CSS3 com @keyframes e transitions.
- Menu hamburger responsivo com JavaScript em /js/menu.js.
- Sitemap.xml e robots.txt.
- Tags de Google Analytics, Google Tag Manager e Search Console nos HTMLs.
