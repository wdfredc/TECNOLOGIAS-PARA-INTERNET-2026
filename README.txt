Projeto Web - ConectaWeb

Esse pacote foi revisado para atender à Ficha de Avaliação da disciplina Tecnologias para Internet.

O que já está implementado:
- HTML semântico com header, nav, main e footer.
- Organização em pastas: /css, /js, /imagens e /secreto.
- Layout responsivo com Flexbox/Grid e media queries.
- Variáveis CSS no :root.
- Animações CSS3 com @keyframes e transitions.
- Menu hamburger responsivo com JavaScript em /js/menu.js.
- Sitemap.xml e robots.txt.
- Tags de Google Analytics, Google Tag Manager e Search Console nos HTMLs.

Antes de entregar/publicar:
1. Publique o site no GitHub Pages.
2. Confira se a URL real é a mesma usada no sitemap.xml e no robots.txt.
3. Substitua os IDs de exemplo:
   - GTM-EXEMPLO1 pelo ID real do Google Tag Manager, se for usar GTM.
   - G-EXEMPLO1234 pelo ID real do GA4.
   - COLOQUE_AQUI_SEU_TOKEN_GSC pelo token real do Search Console.
4. No Google Search Console, envie o sitemap: /sitemap.xml.
5. No Google Analytics, confirme se os acessos aparecem no painel em tempo real.

Atenção: Google Analytics e Search Console dependem de conta Google e site publicado. O código está preparado, mas a confirmação no painel precisa ser feita pelo aluno.
