O que está implementado:
- HTML semântico com header, nav, main e footer.
- Organização em pastas: /css, /js, /imagens e /secreto.
- Layout responsivo com Flexbox/Grid e media queries.
- Variáveis CSS no :root.
- Animações CSS3 com @keyframes e transitions.
- Menu hamburger responsivo com JavaScript em /js/menu.js.
- Sitemap.xml e robots.txt com a URL correta do GitHub Pages.
- Google Analytics 4 configurado com o ID: G-JGPWF4ST33.
- Google Search Console configurado com a meta tag de verificação informada.

URL usada no projeto:
https://wdfredc.github.io/TECNOLOGIAS-PARA-INTERNET-2026/

Antes de entregar/publicar:
1. Envie todos os arquivos para o repositório do GitHub Pages.
2. Aguarde alguns minutos após o commit.
3. Abra o site e pressione Ctrl + F5 para limpar o cache.
4. No Google Search Console, envie o sitemap: /sitemap.xml.
5. No Google Analytics, confira em Relatórios > Tempo real se o acesso aparece.
